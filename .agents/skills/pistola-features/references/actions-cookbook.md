# Pistola actions cookbook

Patterns that validate and render today. Field lists are abbreviated; `window.pistola.manual()` (once available) or `editor/packages/editor/src/lib/assistant/types.ts` is the full schema.

## Getting ids

- **Active level id** (`level_…`): `window.pistola.inspect()`, the MCP tool `pistola_get_workspace`, or the assistant panel header, which shows `structure · level_xxx`.
- **Ids of created nodes:** the `createdNodeIds` in the run result, in action order.
- Inside one batch, use `refId: "$ref_<name>"` on the creating action and the same string wherever an id is expected.

## Primitive assembly (toy objects, furniture blockouts)

```json
[
  { "type": "place_item", "refId": "$ref_hull", "assetId": "primitive-box", "name": "Hull",
    "levelId": "LEVEL", "placement": "explicit", "position": [0, 0, 0], "scale": [0.16, 0.08, 0.40] },
  { "type": "place_item", "assetId": "primitive-box", "name": "Cabin", "parentId": "$ref_hull",
    "levelId": "LEVEL", "placement": "explicit", "allowOverlap": true,
    "position": [0, 0.09, -0.07], "scale": [0.09, 0.06, 0.10] },
  { "type": "place_item", "assetId": "primitive-cylinder", "name": "Mast", "parentId": "$ref_hull",
    "levelId": "LEVEL", "placement": "explicit", "allowOverlap": true,
    "position": [0, 0.09, 0.06], "scale": [0.012, 0.22, 0.012] }
]
```

- Primitives are `box`, `sphere`, `cylinder` (x = diameter; set z too for an elliptic top), `cone`, `torus`, `capsule` and `wedge`, each as `primitive-<name>`.
- `position` is bottom-center, and `scale` is the size in meters, because every primitive is 1 × 1 × 1.
- A wedge slopes along z; rotate it with `rotation: [0, 3.14159, 0]` to flip its direction.
- Every non-root part needs `allowOverlap: true`.
- Run the same object twice only after moving it. Every recipe spawns at the origin, so a second copy collides with the first.

## Architecture

```json
[
  { "type": "create_wall", "refId": "$ref_front", "levelId": "LEVEL", "start": [0, 0], "end": [4, 0], "height": 2.7, "thickness": 0.15 },
  { "type": "create_wall", "levelId": "LEVEL", "start": [4, 0], "end": [4, 3], "height": 2.7, "thickness": 0.15 },
  { "type": "create_slab", "levelId": "LEVEL", "name": "Floor", "polygon": [[0,0],[4,0],[4,3],[0,3]] },
  { "type": "create_roof", "levelId": "LEVEL", "corner1": [0, 0], "corner2": [4, 3], "height": 1.2 },
  { "type": "place_door", "wallId": "$ref_front", "localX": 1.0, "width": 0.9, "height": 2.1 },
  { "type": "place_window", "wallId": "$ref_front", "localX": 3.0, "localY": 1.0, "width": 1.2, "height": 1.0 }
]
```

- Wall points are plan coordinates `[x, z]` in meters.
- `localX` is measured along the wall from its start; `localY` is the sill height.

## Local CAD solids (`build_cad_solid`)

```json
{ "type": "build_cad_solid", "name": "Hull", "spec": {
  "op": "hull",
  "profileXY": [[-1, 0], [1, 0], [1, 0.4], [-1, 0.4]],
  "profileZY": [[-0.3, 0], [0.3, 0], [0.3, 0.4], [-0.3, 0.4]],
  "profileXZ": [[-1, -0.3], [1, -0.3], [1, 0.3], [-1, 0.3]]
}, "roughness": 0.4, "metalness": 0.1 }
```

- Other kernel ops: `box`, `cylinder`, `sphere`, `torus`, `capsule`, `ellipsoid`, `extrude`, `revolve`, `loft`, booleans, `mirror`, arrays.
- `loft` takes `sections` (2D polygons) along `axis` (`y` default) with optional `heights` or `span`.
- `place_cad_body_in_architecture` instances the real mesh into a level. Do not parent items to a CAD body if you want slab lift; those children keep local Y.

## CAD profile extrusion (`execute_cad_brief`)

```json
{ "type": "execute_cad_brief", "brief": {
  "intent": "Sail profile extruded 4 mm",
  "sketchPlans": [{ "plane": "YZ", "entities": [
    { "type": "polyline", "points": [[0,0],[0,0.18],[-0.12,0],[0,0]], "params": { "closed": true } } ] }],
  "operationGraph": [{ "id": "op_sail", "op": "extrude",
    "params": { "sketchIndex": 0, "distance": 0.004, "direction": [1, 0, 0] } }],
  "assumptions": [], "ambiguities": [] } }
```

- Entity types: `line`, `rectangle` (2 corner points), `circle` (center plus `params.radius`), `arc`, `polyline`, `heart` (`params.width` and `params.height`), `ellipse` and `bspline`.
- Other operations: `revolve`, `boolean_union`, `boolean_cut`, `boolean_intersect`, `fillet` and `chamfer`, each with `dependsOn` set to earlier operation ids.
- **Current limit:** only `heart` renders as a true local profile. Other extrusions are regenerated by the CAD helper. On hosts where that helper is a mock, they become a bounding box. Check `/api/cad/health` first.

## Fixing things after a run

| Goal | Action |
|---|---|
| Move or resize a part | `update_item_properties { nodeId, position?, rotation?, scale? }` |
| Nudge | `move_target { nodeId, delta: [dx, dy, dz] }` |
| Remove | `delete_target { nodeId }` (destructive: it needs review or confirmation) |
| Rename | `rename_node { nodeId, name }` |
| Look at the result | `focus_camera_on_nodes { nodeIds }`, then take a screenshot |

## Error messages and fixes

| Message | Cause | Fix |
|---|---|---|
| `Asset "Box" cannot be placed at the requested floor position` | The floor grid ignores height, so the part overlaps another part's footprint | Add `allowOverlap: true` to non-root parts, or move the object to empty floor |
| `This plan changes the scene and must be reviewed before execution` | Mutating plan sent without review confirmation | Use `window.pistola.invoke('run', [actions, { confirmDestructive: true }])` or MCP `pistola_run`. Do not send the prompt through in-app chat. |
| `Action N: ... implicit target` / sequence drift | Action without an explicit id after a create or select | Pass `nodeId`, `levelId` or `wallId` explicitly |
| `$ref_x used before it is defined` | Wrong order, or a ref from another batch | Define it earlier in the same batch, or use the real id |
| `Failed to fetch` | The page cannot reach its API: the static Sites host, CORS, or an offline API | Use a local surface (`window.pistola`, `/run`) that needs no API |
| `... not available in this runtime` (`execute_cad_brief`, `generate_mac_part`) | That surface lacks the CAD or MAC runtime | Use the assistant panel `/run` or `window.pistola`, which carry the full runtime |
| `User Safety: safe` or other odd replies in chat | The free OpenRouter router picked a safety classifier model | Don't plan through the in-app chat; run actions directly, or pick a paid model |
